# 面试/笔试经验知识库 — 设计方案

> 版本：v0.1（待审核）
> 日期：2026-08-09
> 决策依据：用户确认「公开低反爬站点抓取 + 手动粘贴入库；面试题与笔试算法题均要；岗位库降级；先出设计再实现」

## 1. 目标与定位

将 RAG 知识库从「爬虫岗位库」改造为「面试/笔试经验库」：

- **定位**：为 SKILL.md 的「面试建议生成」环节提供真实题库数据支撑
- **核心价值**：面试建议不再只靠 LLM 通用生成，而是基于真实面试/笔试题目
- **数据流**：网上公开面经/题解 → 抓取/粘贴 → LLM 结构化 → ChromaDB → 检索 → 面试建议

```
面试/笔试经验（CSDN/掘金/力扣/手动粘贴）
    │ 入库层（爬虫 + 手动粘贴接口）
    ▼
原始素材（raw 面经文本）
    │ 加工层（LLM 去噪/归并/结构化）
    ▼
面试题库（ChromaDB interview_kb）
    │ 检索层（按公司/岗位/技能/轮次语义检索）
    ▼
对接层（interview_advisor 检索真实题目 → 生成面试建议）
```

## 2. 数据模型（ChromaDB `interview_kb` 集合）

### 2.1 集合结构

| 项 | 设计 |
|---|---|
| Collection 名 | `interview_kb` |
| Embedding | 复用 `BAAI/bge-small-zh-v1.5`（与现有一致） |
| ID | `exp_{公司/岗位/来源}_{内容MD5前12位}`（去重键） |

### 2.2 入库文档（Document，向量化的文本）

```
公司：{company}
岗位：{role}
轮次：{stage}（HR面/业务面/专业面/主管面/终面/笔试）
题目类型：{question_type}（面试问答/手撕算法/系统设计/行为面）
题目：{question}
考察点：{key_points}
参考思路：{reference_answer}
来源：{source_url}
```

### 2.3 Metadata（标量，用于过滤）

| 字段 | 类型 | 说明 |
|---|---|---|
| `company` | str | 公司名（"某公司"/通用则空） |
| `role` | str | 岗位名（"Python后端"/通用则空） |
| `stage` | str | HR面/业务面/专业面/主管面/终面/笔试 |
| `question_type` | str | 面试问答/手撕算法/系统设计/行为面 |
| `source` | str | 来源站点（csdn/juejin/leetcode/manual） |
| `source_url` | str | 原文链接 |
| `collected_at` | str | 入库日期 |
| `quality` | int | 质量分 1-5（LLM 加工时标注） |
| `is_algorithm` | bool | 是否笔试算法题 |

## 3. 入库层

### 3.1 公开低反爬站点爬虫（`experience_crawler.py`）

优先选择反爬较弱、内容公开的站点，复用现有 DrissionPage 浏览器渲染经验（智联方案已验证）：

| 站点 | 抓取内容 | 反爬强度 | 优先级 |
|---|---|---|---|
| CSDN 博客 | 面经文章、面试题总结 | 低 | ★★★ |
| 掘金（juejin.cn） | 面经、题库文章 | 低 | ★★★ |
| 力扣题解区（leetcode.cn） | 笔试算法题 + 题解 | 低-中 | ★★ |
| 知乎专栏 | 面经（公开文章） | 中 | ★★ |
| 牛客网 | 面试经验 | **高（登录墙/验证码）** | 不自动抓，走手动粘贴 |

抓取方式：DrissionPage 浏览器渲染 + BeautifulSoup 解析（复用 `crawl_zhilian_browser` 模式）；分页 + 去重 + 单条失败不崩溃。

### 3.2 手动粘贴入库接口

- `POST /api/exp/upload`：用户粘贴面经原文 + 标注（公司/岗位/轮次/来源链接）→ 走同一加工层入库
- 覆盖牛客/一亩三分地等高反爬平台，用户自行粘贴

### 3.3 批量文件入库（`_ingest_experiences.py`）

支持直接导入整理好的面经文件（.docx / .txt / .md / .json），整份文件作为一条素材走加工层入库：

```bash
python _ingest_experiences.py <面经文件> [<面经文件> ...]
# 示例（可同时传入多份 Word 文档）
python _ingest_experiences.py 面经1.docx 面经2.docx 面经3.md
```

| 扩展名 | 处理方式 |
|---|---|
| `.docx` | python-docx 提取段落 + 表格文本（推荐：用户整理好的 Word 面经） |
| `.txt` / `.md` | 直接读取全文 |
| `.json` | 按素材列表解析（爬虫存档格式） |

无参数运行时，缺省处理 `data/raw/experience/` 下全部素材文件。

### 3.4 入库流程

```
原始文本 → 清洗（去广告/去无关内容）→ LLM 结构化（加工层）→ 去重（按内容MD5）→ upsert 入库
```

## 4. 加工层（LLM 结构化）

`experience_processor.py`，LLM 将原始面经转为结构化题目：

- **去噪**：剔除广告、无关讨论、纯情绪表达
- **归并**：多源同题合并，多源交叉后标注质量分
- **结构化**：提取 公司/岗位/轮次/题目/考察点/参考思路
- **补全**：算法题自动关联力扣题号/题解链接；问答类补充参考答案要点
- **合规**：输出时注明来源 URL；不确定内容标注【待确认】

Prompt 输出 JSON：

```json
{
  "company": "某公司",
  "role": "Python后端",
  "stage": "专业面",
  "question_type": "系统设计",
  "question": "如何设计高并发下单接口？",
  "key_points": ["限流", "库存一致性", "幂等"],
  "reference_answer": "从限流、扣减一致性、幂等角度…",
  "quality": 4,
  "source_url": "https://…"
}
```

## 5. 检索层

`interview_knowledge_base.py`，接口：

| 函数 | 功能 |
|---|---|
| `init_interview_kb()` | 建库/加载 |
| `add_experiences(items)` | 增量入库（按 ID 去重） |
| `search_questions(query, company="", role="", stage="", top_k=10)` | 语义检索 + where 过滤 |
| `get_questions_by_company(company, top_k=20)` | 面试前查"这家公司面什么" |
| `get_algorithm_questions(role="", top_k=20)` | 笔试算法题 |

## 6. 对接层（interview_advisor 改造）

`generate_interview_questions` 流程改为：

```
1. 从 interview_kb 检索真实题目（按岗位类型 + 轮次）
2. 检索到的题目作为"已知真实题目"注入 Prompt
3. LLM 基于真实题目 + 岗位分析 + 用户简历，生成/整理面试问题清单
4. 无命中时退回纯 LLM 生成（降级不阻塞）
```

面试建议的「建议重点准备的案例」「可反问问题」同样优先参考题库命中内容。

## 7. UI 设计（Web）

在简历优化 Tab 之外新增「面试题库」Tab：

- **检索区**：公司/岗位/轮次 筛选 + 关键词搜索 → 展示题目列表（题目/考察点/参考思路/来源链接）
- **入库区**：手动粘贴面经表单（原文 + 公司 + 岗位 + 轮次 + 来源链接）→ 提交入库
- **面试建议区**：与现有优化结果联动，面试建议中的问题清单标注题库命中

## 8. 岗位库降级方案

| 现有模块 | 处理 |

| `jd_crawler.py`（爬虫） | 停用入口脚本，保留代码；不再参与主流程 |

## 9. 合规与风险控制

- 只抓公开可访问页面；高反爬平台走手动粘贴
- 入库内容保留来源 URL，LLM 加工不虚构来源
- 面经为 UGC，仅供求职参考；不承诺真实性，检索结果标注来源
- 参考思路由 AI 生成，标注【AI 整理，仅供参考】
- 负面/敏感内容不入库；控制存储规模

## 11. 实现说明与补充

- **模型加载卡死问题**：模型加载时联网检查 HuggingFace 在受限网络下会长时间重试（表现为接口无响应），已新增 `start_web_offline.py` 启动脚本（设置 `HF_HUB_OFFLINE=1` 后启动 uvicorn），计划任务 `aiagent_web` 改用它启动。
- **手动录入入口**：牛客/一亩三分地等高反爬平台，直接在「面试题库」Tab 下方粘贴面经 → AI 结构化 → 入库。
- **爬虫入口**：`python _crawl_experiences.py`（等价于 `experience_crawler.main()`），或 `python -c "from experience_crawler import crawl_experiences, save_raw_experiences; ..."`。
- **删除/重建集合后必须重启 Web 服务** ⚠️：`_get_interview_collection()` 使用 `lru_cache` 单例缓存集合引用。若在服务运行期间执行 `clear_interview_kb()` 或删除重建 `interview_kb` 集合（如修复索引损坏后重新导入），**运行中的服务进程仍持有指向旧集合（已被删除）的引用**，表现为 `/api/exp/count` 返回 0、`/api/exp/search` 返回空数组，而本地直测正常。操作完成后必须重启 Web 服务（杀掉进程 → 重新运行计划任务 `aiagent_web`）使缓存失效。**推荐顺序**：先停服务 → 清空/重建题库 → 再启动服务。
