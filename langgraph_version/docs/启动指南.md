## 2. 快速启动（推荐方式）

### 方式 A：直接运行（前台）

```bash
cd D:/项目/aiagent/langgraph_version
"D:/项目/aiagent/.venv/Scripts/python.exe" -m uvicorn web_app:app --host 127.0.0.1 --port 8000
```

或使用项目自带入口：

```bash
cd D:/项目/aiagent/langgraph_version
../.venv/Scripts/python.exe main.py web
```

启动后访问 **http://127.0.0.1:8000**，健康检查：**http://127.0.0.1:8000/api/health**。

> ⚠️ 前台方式关闭终端即停止服务，适合临时调试。

### 方式 B：脱离会话常驻（推荐生产/长期运行）

本项目环境下（Git Bash 等终端会话结束时可能连带终止子进程），`start_web.py` 的
`DETACHED_PROCESS` 方式并不总是可靠。实测可靠做法是**通过 Windows 任务计划程序（schtasks）启动**，
进程由 Task Scheduler 服务拉起，完全脱离 bash 进程树：

```python
# 用项目 venv 的 python 执行（避免中文路径在命令行中的编码问题）
cd D:/项目/aiagent
.venv/Scripts/python.exe -c "
import subprocess
subprocess.run(['schtasks', '/create', '/tn', 'aiagent_web',
                '/tr', r'cmd /c D:\项目\aiagent\langgraph_version\start_server.bat',
                '/sc', 'once', '/st', '00:00', '/f'], check=True)
subprocess.run(['schtasks', '/run', '/tn', 'aiagent_web'], check=True)
"
```

启动脚本 `langgraph_version/start_server.bat` 内容（注意：**bat 中不要写中文注释**，
GBK 代码页会把 UTF-8 中文解析坏导致脚本报错；路径用 `%~dp0` 相对定位即可）：

```bat
@echo off
cd /d "%~dp0"
set HF_HUB_OFFLINE=1
set TRANSFORMERS_OFFLINE=1
set HF_HUB_DISABLE_TELEMETRY=1
set HF_HUB_DISABLE_PROGRESS_BARS=1
set MOCK_LLM=0
"%~dp0..\.venv\Scripts\python.exe" -m uvicorn web_app:app --host 127.0.0.1 --port 8000 >> "%~dp0web_out.log" 2>> "%~dp0web_err.log"
```

日志输出到 `langgraph_version/web_out.log` / `web_err.log`。

## 3. 网络受限环境（离线启动）

嵌入模型加载时会联网检查 HuggingFace，无外网时会**长时间卡死重试**。两个解决办法：

```bash
# 方式 1：项目自带离线启动脚本（推荐）
cd D:/项目/aiagent/langgraph_version
../.venv/Scripts/python.exe start_web_offline.py 8000

# 方式 2：手动设置离线环境变量后再启动
export HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1
../.venv/Scripts/python.exe -m uvicorn web_app:app --port 8000
```

模型已缓存于 `~/.cache/huggingface/hub/models--BAAI--bge-small-zh-v1.5` 时，加载约 35s。

## 8. 常见问题（FAQ）

| 现象 | 原因与解决 |
|------|-----------|
| 启动后立刻退出 / 端口未监听 | 终端会话结束连带终止子进程 → 用第 2 节方式 B（schtasks）常驻 |
| 卡在 "Retrying in 1s ... WinError 10060" | 无外网，HuggingFace 检查超时 → 设 `HF_HUB_OFFLINE=1` 离线启动（第 3 节） |
| bat 报 "不是内部或外部命令" 且输出乱码 | bat 内含中文注释被 GBK 误解析 → 保持 bat 纯 ASCII |
| 聊天无智能回答 | 未配置 API Key 且未开 MOCK → `.env` 配置 Key，或设 `MOCK_LLM=1` |
| `Could not import module "web_app"` | 启动时工作目录不是 `langgraph_version` → 先 `cd` 到该目录（bat 中已有 `cd /d %~dp0`） |
| 端口被占用 | 换端口：uvicorn `--port 8001`，或 `.env` 设 `WEB_PORT=8001` |
